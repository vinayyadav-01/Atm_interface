
# 💳 ATM Interface

A simple and interactive ATM Interface built using HTML, CSS, and JavaScript.

## ✨ Features
- 💰 Check Account Balance
- 💸 Cash Withdrawal
- 🏦 Deposit Money
- 🔐 PIN Authentication
- 📊 Transaction Messages
- 🎨 Modern User Interface
- 📱 Responsive Design

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript
